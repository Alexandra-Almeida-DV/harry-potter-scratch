# 🪄 Harry Potter – Jogo de Feitiços (Scratch)

 ![Imagem do jogo](jogo.png)
 https://scratch.mit.edu/projects/1277379970/

Projeto desenvolvido como parte do curso **CS50x – Harvard**.

## 🎮 Descrição
Neste jogo interativo, Harry precisa abrir uma porta para encontrar seus amigos.
O jogador deve escolher o feitiço correto para avançar.

## 🧠 Conceitos aplicados
- Variáveis
- Condicionais
- Laços de repetição
- Blocos personalizados
- Eventos e mensagens
- Narrativa interativa

## 🛠️ Tecnologias
- Scratch (scratch.mit.edu)

## 📚 Curso
CS50x – Introduction to Computer Science  
Harvard University
